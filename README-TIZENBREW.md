# MU7009 Home Launcher – TizenBrew

Dieses Projekt ist ein Google-TV-inspirierter Launcher für den Samsung MU7009.

## Aktueller Stand
- Oberfläche in index.html vorhanden
- App-Kacheln für YouTube, Netflix, Prime Video, Disney+ und DAZN
- GitHub Pages eingerichtet

## Wichtig
Dies ist bisher ein Design-Prototyp.
Die Installation als TizenBrew-Modul und das Starten nativer Samsung-Apps sind noch nicht umgesetzt.

## Nächster Schritt
Kompatibilität mit TizenBrew prüfen und eine passende Modulschnittstelle entwickeln.
