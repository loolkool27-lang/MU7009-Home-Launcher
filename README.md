# MU7009 Home Launcher

Kostenloser, Google-TV-inspirierter **Design-Prototyp** für Samsung MU7009.

## Vorschau
`index.html` im Browser öffnen. Enthält einen fest eingebauten, stilisierten Berg-Sonnenuntergang, Uhr, Fernbedienungs-/Tastaturnavigation und vier App-Kacheln.

## Wichtig
Dies ist **noch kein installierbares TizenBrew-Modul**. Die Kacheln starten noch keine Samsung-Apps. Für TizenBrew müssen die Modul-Schnittstelle und die auf dem MU7009 verfügbaren App-Startmethoden geprüft und implementiert werden. Nicht als fertiges TV-Modul installieren.
